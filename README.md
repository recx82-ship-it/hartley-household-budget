A working household budget site for the Hartley family — Marcus, Elena, Sophie (9) and Leo (6) of Bristol. It runs in a browser from static files with no network request, on desktop and on a phone: a dashboard (income, spent, left over, monthly plan usage, spending-by-category chart, budgets closest to the limit, upcoming bills, recent transactions), a transactions ledger for October and November 2026 with add, edit, delete, search and filters that persists in localStorage, twelve budgets with live progress bars and editable limits, four savings goals with add-funds and goal creation, and reports comparing the two months with plain-English insights and a CSV export. Every figure is worked out from the transaction ledger, so the pages can never disagree with each other.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `app/index.html` directly in a browser.
